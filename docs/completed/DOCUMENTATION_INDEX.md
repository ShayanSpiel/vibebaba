### Documentation Issues

**Can't find what you're looking for?**
1. Use the "By Topic" section above
2. Search for keywords in this index
3. Browse the appropriate docs/ subfolder
4. Check [docs/guides/#done_TECHNICAL_REFERENCE.md](docs/guides/#done_TECHNICAL_REFERENCE.md)

**Documentation outdated?**
1. Check file timestamps (in file headers)
2. Review related files in same folder
3. Update and note changes in file header

1. Read [DOCUMENTATION_AND_PLANNING_RULES.md](DOCUMENTATION_AND_PLANNING_RULES.md)
