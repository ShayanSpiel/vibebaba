## 🔧 Troubleshooting

**Issue resolution and debugging guides**

#### **[AI_GENERATION_ISSUES_AND_FIXES.md](troubleshooting/AI_GENERATION_ISSUES_AND_FIXES.md)** ⭐
**Critical analysis of AI generation issues with solutions**

**Issue #1: Repetitive/Unwanted Generation**
- **Problem:** AI adds same features regardless of request (e.g., always adds shoe size selector)
- **Root Causes:**
  - Over-prescriptive component templates
  - Weak component selection logic
  - No user intent validation
- **Solutions:**
  - Enhanced component selection prompts
  - Intent validation step
  - Granular component variants

**Issue #2: Poor Implementation Quality**
- **Problem:** AI understands requirements but can't implement properly (broken spinners, incomplete CRUD)
- **Root Cause:** Example system EXISTS but NOT BEING USED! 🚨
- **Solutions:**
  - Use `getEnhancedDesignSystemPromptWithExamples()` (1 line change!)
  - Add interactive patterns library
  - Increase MCP timeout with caching
  - Add fallback mechanisms

**Complete Implementation Checklist:**
- [ ] Fix #1: Enable example system (CRITICAL - 5 minutes)
- [ ] Fix #2: Improve component selection (15 minutes)
- [ ] Fix #3: Add intent validation (20 minutes)
- [ ] Fix #4: Add interactive patterns (1 hour)
- [ ] Fix #5: Strengthen MCP context (30 minutes)

**Expected Impact:**
- 90% reduction in unwanted features
- 90% correct spinner implementations (up from 60%)
- 80% correct complex interactions (up from 25%)

## 🎯 The Complete 16-Step App Generation Process

**Documented across infrastructure files:**

1. **User Input** → Landing page chat
2. **Planning Phase** → AI analyzes & generates plan (`app/api/ai/plan/route.ts`)
3. **App Type Detection** → AI categorizes app type
4. **Component Selection** → AI determines needed components
5. **MCP Context** → Gathers real-world examples (`lib/mcp-background-helper.ts`)
6. **Design System** → Selects colors, fonts, patterns (`lib/enhanced-design-prompt.ts`)
7. **Example Selection** → Fetches implementation examples (`lib/example-selector.ts`) ⚠️ Currently not used!
8. **AI Generation** → Generates complete code (`app/api/ai/prototype/route.ts`)
9. **Validation** → Checks HTML/CSS/JS/structure (`lib/validation/`)
10. **AI Debugging** → Auto-fixes errors (3 attempts) (`lib/services/ai-debugger.ts`)
11. **Error Logging** → Tracks issues (`lib/services/validation-error-logger.ts`)
12. **Backend Config** → Generates PocketBase schema (if requested)
13. **File Processing** → Prepares multi-page structure
14. **Storage** → Saves to database
15. **Live Preview** → Renders in iframe (`components/prototype/CodePreview.tsx`)
16. **Iteration** → Chat-based refinement (`app/api/ai/chat/route.ts`)

**See: [VALIDATION_AND_DEBUGGING_SYSTEM.md](infrastructure/VALIDATION_AND_DEBUGGING_SYSTEM.md) for complete architecture**
